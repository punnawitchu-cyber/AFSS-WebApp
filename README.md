# AFSS (Automatic Fire Suppression System)

Final Project: ระบบดับเพลิงอัตโนมัติ

โครงงานนี้เป็นการพัฒนาระบบดับเพลิงอัตโนมัติ (AFSS) โดยใช้เซนเซอร์ตรวจจับควัน อุณหภูมิ และเปลวไฟ เพื่อตรวจสอบความผิดปกติที่อาจเกิดจากเหตุเพลิงไหม้ พร้อมระบบแจ้งเตือนและการสั่งงานระบบดับเพลิง ซึ่งมีทั้งการทำงานแบบอัตโนมัติและการสั่งงานด้วยตนเอง

## Features
- ตรวจสอบค่าจากเซนเซอร์
- ตรวจจับความผิดปกติที่อาจเกิดจากไฟไหม้
- แสดงข้อมูลเซนเซอร์ผ่าน Web Dashboard
- ระบบแจ้งเตือนเมื่อพบเหตุผิดปกติ
- ควบคุมระบบดับเพลิง
- บันทึกประวัติเหตุการณ์
